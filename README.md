# javascript-lotto-precourse

## 구현할 기능 목록  

---

### 구입 금액 입력 기능  
- 사용자로부터 구입 금액을 입력받는다.  
- 입력값이 숫자가 아니거나 1,000원 단위가 아닐 경우 예외를 발생시킨다.  
- 구입 금액이 0 이하일 경우 예외를 발생시킨다.  
- 유효한 금액일 경우 해당 금액을 반환한다.  

---

### 로또 발행 기능  
- 구입 금액을 1,000으로 나누어 구매 가능한 로또 개수를 계산한다.  
- 1장에서 중복되지 않는 1~45 사이의 숫자 6개를 생성한다.  
- `Random.pickUniqueNumbersInRange(1, 45, 6)`을 사용하여 난수를 생성한다.  
- 생성된 번호는 오름차순으로 정렬한다.  
- 발행된 모든 로또 번호를 출력한다.  

---

### 당첨 번호 입력 기능  
- 사용자로부터 쉼표(`,`)로 구분된 6개의 당첨 번호를 입력받는다.  
- 입력값이 숫자가 아니거나 1~45 범위를 벗어날 경우 예외를 발생시킨다.  
- 중복된 번호가 있을 경우 예외를 발생시킨다.  
- 유효한 당첨 번호 6개를 배열로 반환한다.  

---

### 보너스 번호 입력 기능  
- 사용자로부터 보너스 번호를 입력받는다.  
- 입력값이 숫자가 아니거나 1~45 범위를 벗어날 경우 예외를 발생시킨다.  
- 당첨 번호와 중복될 경우 예외를 발생시킨다.  
- 유효한 보너스 번호를 반환한다.  

---

### 당첨 결과 계산 기능  
- 사용자가 구매한 각 로또 번호를 당첨 번호와 비교한다.  
- 일치한 개수를 계산하고, 보너스 번호 일치 여부를 확인한다.  
- 일치 개수에 따라 등수를 판별한다.  
  - 6개 일치 → 1등  
  - 5개 + 보너스 일치 → 2등  
  - 5개 일치 → 3등  
  - 4개 일치 → 4등  
  - 3개 일치 → 5등  
- 등수별 당첨 횟수를 집계한다.  

---

### 결과 출력 기능  
- 각 등수별 당첨 개수와 상금을 출력한다.  
- 전체 상금과 수익률을 계산한다.  
- 수익률 = (총 상금 / 구입 금액) × 100  
- 수익률은 소수점 둘째 자리에서 반올림하여 `%` 단위로 출력한다.  

---

### 예외 처리 기능  
- 입력값이 잘못된 경우 `[ERROR]`로 시작하는 메시지를 출력한다.  
- 예외 발생 시 해당 단계부터 다시 입력을 받는다.  
- 프로그램 종료 시 `process.exit()`를 사용하지 않는다.
